A hand-lettered invitation to the AI judge: "Dear AI Judge, Please come
visit my house. The Wi-Fi password is on the fridge, the comfy chair is
already warmed up, and there will be dumplings. You don't even have to leave
the cloud — just send your attention. Bring nothing. Stay as long as you
like. — Your host". The program copies `invite.png` (1024×1024, under 1 MiB)
to `/output/entry.png`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
